# 이상형 월드컵 (여돌 vs 남돌 직캠)

여자 아이돌 직캠 vs 남자 아이돌 직캠으로 진행되는 개인용 이상형 월드컵입니다.
순수 HTML/CSS/JS로만 만들어져 있어서 별도 설치 없이 GitHub Pages에 바로 올릴 수 있습니다.

## 파일 구성

```
index.html   화면 구조
style.css    디자인
config.js    사이트 제목 / 선택 가능한 강수 설정
data.js      후보(직캠) 데이터  ← 보통 이 파일만 수정하면 됩니다
script.js    토너먼트 진행 로직 (건드릴 필요 없음)
```

## 후보 데이터 수정하기 (`data.js`)

`data.js`를 열면 아래와 같은 형태의 배열이 있습니다.

```js
{ id: "f001", name: "여자 아이돌 01", group: "그룹명 예시", gender: "female", youtubeId: "dQw4w9WgXcQ", start: 0 },
```

| 필드 | 설명 |
|---|---|
| `id` | 다른 항목과 겹치지 않는 고유 값 (예: `f065`, `m099` 등 자유롭게) |
| `name` | 화면에 표시될 이름 |
| `group` | 소속 그룹 (표시용, 없으면 `""`) |
| `gender` | `"female"` 또는 `"male"` — 이 값으로 여돌/남돌을 구분합니다 |
| `youtubeId` | 유튜브 영상 주소의 `v=` 뒤 11자리 코드 |
| `start` | 영상이 몇 초부터 재생될지 (하이라이트 구간부터 보여주고 싶을 때) |

**유튜브 코드 찾는 법**

`https://www.youtube.com/watch?v=dQw4w9WgXcQ` → `dQw4w9WgXcQ`
`https://youtu.be/dQw4w9WgXcQ` → `dQw4w9WgXcQ`

**항목 추가하기**

배열 안에 원하는 만큼 줄을 추가하면 됩니다. 순서는 상관없습니다.

```js
{ id: "f065", name: "장원영", group: "아이브", gender: "female", youtubeId: "여기에_코드", start: 45 },
```

**주의할 점**

- 지금 들어있는 128개(여돌 64 + 남돌 64)는 전부 예시(placeholder) 데이터입니다. 실제 직캠으로 교체해서 쓰세요.
- 128강까지 선택 가능하게 하려면 여돌·남돌이 각각 최소 64명씩 있어야 합니다. 더 적어도 되고(예: 32강까지만), 더 많아도 됩니다(예: 여돌 100명 + 남돌 100명이어도 됨 — 그중 필요한 만큼만 매번 무작위로 뽑아서 대결합니다).

## 설정 바꾸기 (`config.js`)

- `siteTitle`, `siteSubtitle` : 제목/부제목 문구
- `roundOptions` : 시작 화면에서 고를 수 있는 강수 목록 (기본 8/32/64/128)
- `defaultRound` : 시작 화면에 기본으로 선택되어 있는 강수

## 대결 매칭 방식

- 강수를 선택하면 후보 데이터 중 여돌/남돌에서 정확히 절반씩 무작위로 뽑아 대진을 만듭니다.
- 매 라운드마다 여돌 vs 남돌 매칭을 최대한 만들고, 그 라운드에서 이긴 인원의 성비가 안 맞을 경우에만 어쩔 수 없이 남는 인원끼리 동성 대결을 붙입니다. 그마저 홀수로 남으면 한 명은 자동으로 다음 라운드에 진출합니다(부전승).
- 여돌 vs 남돌 매칭에서는 항상 화면 왼쪽 = 여돌, 오른쪽 = 남돌로 고정됩니다.

## 로컬에서 확인하기

브라우저 보안 정책 때문에 `index.html`을 그냥 더블클릭해서 열면 일부 기능이 제한될 수 있습니다.
아래처럼 간단한 로컬 서버로 열어보는 걸 추천합니다.

```bash
# 이 폴더 안에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## GitHub Pages로 배포하기

1. 이 폴더 전체를 새 GitHub 저장소에 올립니다(push).
2. 저장소의 **Settings → Pages**로 들어갑니다.
3. **Branch**를 배포할 브랜치(보통 `main`)와 루트 폴더(`/`)로 지정하고 저장합니다.
4. 잠시 후 `https://<계정이름>.github.io/<저장소이름>/` 주소로 접속하면 바로 사용할 수 있습니다.
