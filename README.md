# 아이돌 댄스 챌린지 월드컵 (여돌 vs 남돌)

여자 아이돌 댄스 챌린지 숏츠 vs 남자 아이돌 댄스 챌린지 숏츠로 진행되는 개인용 이상형 월드컵입니다.
순수 HTML/CSS/JS로만 만들어져 있어서 별도 설치 없이 GitHub Pages에 바로 올릴 수 있습니다.

## 파일 구성

```
index.html   화면 구조
style.css    디자인 (세로 숏츠 영상에 맞춘 9:16 레이아웃)
config.js    사이트 제목 / 선택 가능한 강수 설정
data.js      후보(댄스 챌린지 숏츠) 데이터  ← 보통 이 파일만 수정하면 됩니다
script.js    토너먼트 진행 로직 (건드릴 필요 없음)
```

## 후보 데이터 수정하기 (`data.js`)

`data.js`를 열면 아래와 같은 형태의 배열이 있습니다.

```js
{ id: "f01", name: "로제 (ROSÉ)", group: "SOLO", song: "APT. (Feat. Bruno Mars)", gender: "female", youtubeId: "m7AD2GKqI10", start: 0 },
```

| 필드 | 설명 |
|---|---|
| `id` | 다른 항목과 겹치지 않는 고유 값 |
| `name` | 화면에 표시될 이름 (그룹명 또는 솔로 아티스트명) |
| `group` | 세대 · 데뷔년월 (표시용, 없으면 `""`) — 멤버 솔로/유닛 곡은 `"SOLO"` 또는 `"유닛 · ..."`으로 표시 |
| `song` | 곡 제목 (표시용, 없으면 `""`) |
| `gender` | `"female"`(여돌) 또는 `"male"`(남돌) — 이 값으로 구분합니다 |
| `youtubeId` | 유튜브 Shorts/영상 주소의 `v=` 또는 `/shorts/` 뒤 11자리 코드 |
| `start` | 영상이 몇 초부터 재생될지 |

## 현재 들어있는 데이터

- 여돌 32개, 남돌 32개, 총 64개 — 정확히 32 vs 32로 64강까지 진행할 수 있습니다
- 전부 유튜브 **숏츠(댄스 챌린지 영상)** 기준으로 채웠습니다
- 그룹/아티스트는 oEmbed·해시태그·공식 채널 확인을 거쳐 실제 곡을 소유한 아티스트 기준으로 정리했습니다. 사용자가 준 원래 추측과 실제 확인 결과가 달랐던 항목들은 `data.js` 주석에 표시해뒀습니다(예: "Rover"는 CORTIS가 아니라 EXO 카이 솔로, "VIBE"는 SEVENTEEN이 아니라 BIGBANG 태양 솔로, "MANIAC"은 VIVIZ(비비지)의 자체 곡 — Stray Kids에도 동명곡이 있어 혼동했지만 여돌 항목이 맞음).
- 일부는 그룹 활동이 아니라 멤버 개인 솔로 곡(로제·지수·나연·태양·태민·카이·전소미·이채연·최예나)이라 `group`을 `"SOLO"`로 표시하고 소속 그룹은 주석에 남겼습니다.

## 세로 영상(Shorts) 레이아웃

댄스 챌린지 숏츠는 9:16 세로 영상이라, `style.css`의 `.video-wrap`을 세로 비율로 맞추고 카드 폭도 좁게 조정했습니다. 다른 프로젝트(가로 MV 기준)와 디자인 값이 다른 부분입니다.

## 설정 바꾸기 (`config.js`)

- `siteTitle`, `siteSubtitle` : 제목/부제목 문구
- `roundOptions` : 시작 화면에서 고를 수 있는 강수 목록 (기본 8/16/32/64)
- `defaultRound` : 시작 화면에 기본으로 선택되어 있는 강수

## 대결 매칭 방식

- 강수를 선택하면 후보 데이터 중 여돌/남돌 그룹에서 정확히 절반씩 무작위로 뽑아 대진을 만듭니다.
- 매 라운드마다 여돌 vs 남돌 매칭을 최대한 만들고, 인원이 안 맞을 경우에만 동성끼리 대결합니다. 홀수로 남으면 한 팀은 자동으로 다음 라운드에 진출합니다(부전승).
- 여돌 vs 남돌 매칭에서는 항상 화면 왼쪽 = 여돌, 오른쪽 = 남돌로 고정됩니다.

## GitHub Pages로 배포하기

1. 이 폴더 전체를 새 GitHub 저장소에 올립니다(push).
2. 저장소의 **Settings → Pages**로 들어갑니다.
3. **Branch**를 배포할 브랜치(보통 `main`)와 루트 폴더(`/`)로 지정하고 저장합니다.
4. 잠시 후 `https://<계정이름>.github.io/<저장소이름>/` 주소로 접속하면 바로 사용할 수 있습니다.
