# 원조 아이돌 챌린지 월드컵

여돌 vs 남돌, 모든 대결이 이성 매칭으로 진행되는 이상형 월드컵입니다.
"특정 챌린지를 따라 하는" 월드컵이 아니라, **그 챌린지를 처음 만든 원조 아이돌**을 겨루게 하는 컨셉입니다.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 실제 월드컵 페이지 (이 파일을 열면 게임이 시작됩니다) |
| `data.js` | **항목 데이터.** 아이돌/챌린지를 추가·수정·삭제하려면 이 파일만 고치면 됩니다 |
| `app.js` | 대진 생성, 매칭, 저장 등 핵심 로직 (평소엔 안 건드려도 됨) |
| `style.css` | 디자인 |
| `editor.html` / `editor.js` | 브라우저에서 `data.js`를 폼으로 편하게 고치고 새 파일로 내려받는 도구 |

## 데이터 수정하는 두 가지 방법

1. **직접 수정**: `data.js`를 텍스트 에디터로 열어서 배열 안에 항목을 추가/수정합니다. 파일 맨 위 주석에 각 필드 설명이 있습니다.
2. **편집기 사용**: `editor.html`을 브라우저로 열고 폼에서 수정한 뒤 "data.js 다운로드"를 누르면 새 파일이 만들어집니다. 이 파일로 기존 `data.js`를 덮어쓰면 됩니다.

새 항목을 추가할 때 가장 중요한 건 `gender` 값을 "F"(여돌) / "M"(남돌)로 정확히 넣는 것과, `youtubeId`에 유튜브 영상 주소의 `v=` 뒤 11자리 코드만 넣는 것입니다.

## 대결 방식

- 시작 화면에서 8강 / 32강 / 64강 / 128강 중 선택합니다. 등록된 데이터 수가 해당 강수보다 적으면 그 버튼은 자동으로 비활성화됩니다.
- 매 라운드마다 살아남은 인원을 여돌/남돌로 나눠서 최대한 이성끼리 무작위 매칭합니다. 인원수가 맞지 않아 남는 쪽은 동성끼리 매칭됩니다.
- 진행 상황은 브라우저 로컬 저장소에 자동 저장되어 새로고침해도 이어할 수 있습니다. "처음부터" 버튼으로 언제든 초기화할 수 있습니다.
- 진행 중 "대진표" 버튼으로 지금까지의 결과를 라운드별로 볼 수 있습니다.

## 깃허브 페이지로 배포하기

1. 이 폴더 전체를 깃허브 저장소에 올립니다 (새 저장소를 만들고 파일을 업로드하면 됩니다).
2. 저장소의 **Settings → Pages**로 들어갑니다.
3. **Branch**를 `main`(또는 사용 중인 브랜치), 폴더는 `/ (root)`로 선택하고 저장합니다.
4. 몇 분 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 접속하면 됩니다.
5. 데이터를 바꾼 새 `data.js`를 올릴 때마다 자동으로 사이트에 반영됩니다.

## 참고

- 각 항목의 `source` 필드에는 조사 과정에서 참고한 기사/자료 링크를 넣어뒀습니다. 원조 여부가 애매하거나 마음에 안 드는 항목은 자유롭게 빼거나 바꿔주세요.
- 현재 32개(여돌 16 · 남돌 16) 데이터가 들어 있어 32강까지 즉시 플레이 가능합니다. 64강/128강을 열려면 데이터를 그만큼 더 추가하면 됩니다.
